星之翼战绩分析 · Windows v1.13

解压完整文件夹，运行“星之翼战绩分析.exe”。保留 avatars 目录和官网指南、助手、刷新脚本。

本次更新：
1. 队友战绩主表取消角色汇总列。选中队友后，展开下方“队友角色与胜率”，每个角色单独一行，显示头像、共同场数、胜场、负场和胜率。支持排序，切换队友或模式后自动更新。
2. PC 图标改为安卓同款：原游戏图标内带“战绩”二字。文件图标、窗口图标和任务栏图标使用同一图案。

保留上版功能：对手角色独立展开区，角色逐行显示；首次启动默认字体 100%，已有的字号设置保留，七档字号和深浅主题位于“设置”。

升级方法：关闭旧版，将旧程序旁的 data、official-web、ui-settings.json 复制到新版程序旁，保留战绩、独立网页登录状态和界面设置；也可备份全部赛季 JSON 后导入新版。请保留旧版数据。

PC 八个菜单位于左侧单列。账号 / 赛季、对战模式与排序移到右侧栏；赛季概览的刷新按钮、状态说明和场次、胜负、胜率、MVP 指标也位于右侧，支持纵向滚动。中间区域用于显示战绩与图表。排行榜取消段位列。导入与官网获取在“设置”。赛季概览可刷新新增战绩。首次使用或登录过期时，需要在对应官网网页完成登录与绑定；多个账号可使用不同网页。

只显示所选本人账号的 UID。队友、对手及排行榜其他玩家的 UID 隐藏，相关统计 CSV 不包含其他玩家 UID 或识别方式说明。JSON 备份保留完整原始数据，供再次导入与合并。

匹配、天梯和 1v1、2v2 可分别分析，支持多账号与赛季汇总。逐场详情显示各玩家战斗数据和可用天梯分数；分数走势位于赛季概览底部。排行榜包含国服、亚服、日本服的公开前 100 名。
统计以已取得的战绩为准。队友胜率是共同对局胜率，对手与排行榜中的胜率是你与该玩家交手的胜率。
