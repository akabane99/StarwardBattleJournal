导出星之翼赛季战绩 v1.7

  1. 把上面的蓝色按钮拖到浏览器书签栏。
  2. 打开官方战绩网站，自行登录并绑定角色。
  3. 在官网页面点击该书签，选择当前或历史赛季。
  4. 可选择已有战绩文件，启用或关闭“增量获取”。完成后点击“开始导出”。
  5. 将下载的 JSON 导入电脑程序“导入 / 合并 JSON”。已有对局不会重复计数，缺失详情会补齐。

增量获取

先在电脑软件点击“导出数据”或“备份全部赛季”，也可以使用安卓导出的同类 JSON。书签中的文件选择只在本机读取文件；按官网当前账号、区服和所选赛季比较。未选择文件或取消勾选时完整获取。

增量模式仍查询逐场列表以查漏，只跳过已有且详情完整的对局。缺少玩家输出等六项详情或天梯四人分数的旧记录会重新获取详情。吸锁定比例按接口值显示；未返回的项目显示未记录。下载的增量文件需要与原有数据合并，不能单独代表全赛季战绩。

多账号网页

点击电脑程序“获取官网战绩”打开管理器，可同时开启八个独立登录网页。各网页首次分别登录一次，在收藏夹栏点击已准备好的导出助手（Ctrl+Shift+B 显示）。导出文件下载到各自的文件夹，程序自动导入并按账号、区服、赛季合并。网页档案保存在程序旁 official-web，不需要每次重新切换账号验证；官网登录过期时仍需重新登录。请完整保留此文件夹，不要与其他人分享里面的浏览器登录资料。

新版电脑功能

逐场记录左边我方、右边敌方，中间胜负和本人实际积分增减；天梯显示每名玩家战前 → 战后分数。角色头像离线显示。顶部可设置浅色 / 深色、50% 到 150% 七档字号（默认 50%）、按场次 / 胜率升降序；左边“全部模式”汇总四种模式。分数日期走势分别显示两种天梯，可按日期筛选和导出日报。

旧版与安卓数据

复制旧版程序旁的 data 文件夹到新程序旁，使用“打开本机缓存”；也可直接多选旧 JSON 导入。当前赛季数据和全部赛季备份支持电脑 / 安卓互导。旧文件未记录的四人分数需要重新导入原始官网 JSON 或增量补查。

场数与日期

四种模式分别分页直到空页，尝试补查较早时间段；官网天梯汇总与逐场列表有差异时保留范围提示。分页结束不保证整季齐全，多次查询可以合并累积。图表仅绘制实际取得的本人天梯分数，日期为北京时间，缺失分数不填零。

无法拖拽时：复制书签地址
