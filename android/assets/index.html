本机数据与导出

说明

CSV 默认包含当前账号赛季的全部适用模式；选择全部模式时导出合计。其他筛选不影响导出。单赛季 JSON 与 Windows 战绩分析版互通；全部赛季备份也可在新版电脑端导入。

统计口径与使用方法

四种模式分别计算。1v1 对位统计双方阵容角色共同出现时的整场结果；2v2 个人对位只计算本人角色，同场相同敌方角色计一次。

队伍组合包含双方各两人，A+B 与 B+A 合并，A+A 保留。无法识别本人时，完整双方队伍仍可用于不带个人筛选的组合统计。

多次查询按完整对局 ID 去重，保留此前独有记录，补齐个人与队伍详情。不同账号、区服、赛季分别保存。字段冲突时取消本批次。

“分页已读完”不表示整季记录齐全。页面会与官网天梯汇总比较，缺失场次不会补造。导出前请注意记录范围。

官网获取：进入官网页登录并绑定角色，然后点击顶部“选择赛季并获取”。可选当前或历史赛季，完成后点击“返回分析”。也可导入电脑已有 JSON。

数据保存在应用内部；卸载前请备份。应用内自动保留上一次成功导入前的备份，可在下面恢复。
